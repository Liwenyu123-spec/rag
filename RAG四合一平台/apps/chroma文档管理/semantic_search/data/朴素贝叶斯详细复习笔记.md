## 一、贝叶斯定理在分类里干什么

要预测类别 $c$，看特征 $x$ 时选后验最大的类：

$$
\hat{c}=\arg\max_c P(c\mid x)
$$

贝叶斯定理：

$$
P(c\mid x)=\frac{P(x\mid c)\,P(c)}{P(x)}
$$

分母 $P(x)$ 对所有类一样，比较时可不算。于是：

$$
\hat{c}=\arg\max_c\ \underbrace{P(x\mid c)}_{\text{类条件似然}}\ \underbrace{P(c)}_{\text{先验}}
$$

人话：看「这个类有多常见」×「这个类有多像会生成当前特征」。

## 二、「朴素」假设与三种模型

### 2.1 条件独立假设

假设给定类别后，各特征独立：

$$
P(x\mid c)=\prod_{j=1}^{d}P(x_j\mid c)
$$

现实中特征常相关，但这个近似让估计变简单，文本等高维稀疏场景往往仍然好用。

### 2.2 sklearn 三件套

| 模型 | 特征假设 | 典型场景 |
| --- | --- | --- |
| `GaussianNB` | 连续特征 ~ 高斯 | 少量连续表数据 |
| `MultinomialNB` | 计数 / TF 等非负离散 | **文本词频**、词袋 |
| `BernoulliNB` | 0/1 是否出现 | 二值词袋 |

文档分类首选常想 **MultinomialNB**（配合 `CountVectorizer` / `TfidfVectorizer`）。

## 三、文本分类与拉普拉斯平滑

### 3.1 词袋流程

```text
原始文本 → 分词/向量化（词频或 TF-IDF）→ MultinomialNB.fit → predict
```

### 3.2 零概率问题与平滑

某词在某类训练里从没出现 → $P(w\mid c)=0$ → 整条连乘变 0（太狠）。

**拉普拉斯平滑（加一平滑）**：给计数加一个很小的伪计数，避免零概率。  
sklearn 里对应 `alpha`（默认常为 1.0）。

### 3.3 先验

`fit` 时可用各类样本比例估 $P(c)$；也可用 `class_prior` / 样本权重等方式干预（了解即可）。

## 四、和逻辑回归怎么选

| | 朴素贝叶斯 | 逻辑回归 |
| --- | --- | --- |
| 速度 | 极快，闭式/计数估计 | 要迭代优化 |
| 数据 | 小样本、高维稀疏也常稳 | 更吃特征质量与正则 |
| 假设 | 强独立假设 | 直接建模 $P(c\mid x)$ |
| 概率 | 有后验，但可偏校准 | 概率通常更「像样」（仍要验证） |

垃圾邮件、主题分类、基线模型：朴素贝叶斯很合适。  
需要细调决策边界、特征交互强：优先逻辑回归 / 树 / 线性 SVM 等。

## 五、综合代码（逐行注释）

```python
import numpy as np  # 数值
from sklearn.model_selection import train_test_split  # 划分
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer  # 文本向量化
from sklearn.naive_bayes import MultinomialNB, GaussianNB  # 两种 NB
from sklearn.pipeline import Pipeline  # 流水线
from sklearn.metrics import classification_report, accuracy_score  # 评估
from sklearn.datasets import make_classification  # 造连续表数据
from sklearn.preprocessing import StandardScaler  # 高斯 NB 前可缩放（可选）

# ---------- 文本：垃圾邮件风格小例子 ----------
texts = [  # 语料
    "免费 送 优惠券 点击 领取",  # 垃圾倾向
    "限时 打折 马上 购买",  # 垃圾
    "发票 代开 联系 微信",  # 垃圾
    "明天 开会 请 准时 到场",  # 正常
    "项目 进度 下周 汇报",  # 正常
    "请 查收 会议 纪要 附件",  # 正常
    "中奖 通知 点击 链接",  # 垃圾
    "团建 周五 下午 集合",  # 正常
] * 20  # 放大一点便于划分
y_text = np.array(([1, 1, 1, 0, 0, 0, 1, 0] * 20))  # 1=垃圾 0=正常

X_tr, X_te, y_tr, y_te = train_test_split(  # 划分
    texts, y_text, test_size=0.3, random_state=42, stratify=y_text  # 分层
)

pipe = Pipeline([  # 词袋 + 多项式 NB
    ("vect", CountVectorizer()),  # 词频向量
    ("clf", MultinomialNB(alpha=1.0)),  # 拉普拉斯平滑
])
pipe.fit(X_tr, y_tr)  # 训练
pred = pipe.predict(X_te)  # 预测
print("文本 MultinomialNB")  # 标题
print(classification_report(y_te, pred, digits=4))  # 报告

# TF-IDF 也常配 MultinomialNB（非负）
pipe_tfidf = Pipeline([  # TF-IDF 管线
    ("tfidf", TfidfVectorizer()),  # TF-IDF
    ("clf", MultinomialNB(alpha=0.5)),  # 略小 alpha
])
pipe_tfidf.fit(X_tr, y_tr)  # 训练
print("TF-IDF Acc:", round(accuracy_score(y_te, pipe_tfidf.predict(X_te)), 4))  # 准确率

# ---------- 连续特征：GaussianNB ----------
X, y = make_classification(  # 造表数据
    n_samples=1000, n_features=8, n_informative=5, random_state=42  # 规模
)
X_tr, X_te, y_tr, y_te = train_test_split(  # 划分
    X, y, test_size=0.3, random_state=42, stratify=y  # 分层
)
gnb = GaussianNB()  # 高斯朴素贝叶斯
gnb.fit(X_tr, y_tr)  # 训练（估每类每维均值方差）
print("GaussianNB Acc:", round(accuracy_score(y_te, gnb.predict(X_te)), 4))  # 评估
print("class prior:", np.round(gnb.class_prior_, 4))  # 先验
```

## 六、易错点与自测

1. 文本用 `GaussianNB`（应对词频用多项式/伯努利）。  
2. `MultinomialNB` 喂了含负值的特征（如未处理的标准化结果）。  
3. 完全不平滑，测试集新词把概率打成 0。  
4. 把「朴素」当成模型很傻——它是独立假设，不是效果一定差。  
5. 只看训练集准确率。  

自测：决策规则比的是什么？朴素假设是什么？文本常用哪个 NB？`alpha` 干什么？  
答案：先验×似然（后验）；特征条件独立；MultinomialNB；平滑防零概率。

## 七、一句话收束

> 朴素贝叶斯用「先验 × 类条件概率」做分类，靠独立假设换速度与简洁；文本词袋加平滑是经典强基线，表数据则按特征类型在高斯/多项式间选型。
