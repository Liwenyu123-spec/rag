# RAG 四合一综合平台（另存副本）

把下面四个项目合并到同一入口，**不覆盖**仓库根目录里的原项目：

| 子项目 | 端口 |
|--------|------|
| 基础聊天机器人 | http://127.0.0.1:8000/ |
| 带安全校验的聊天机器人 | http://127.0.0.1:8001/ |
| 社交媒体文案和电商内容生成 | http://127.0.0.1:8002/ |
| chroma文档管理（Native RAG） | http://127.0.0.1:8003/ |
| **统一门户** | http://127.0.0.1:8100/ |

## 启动

在仓库根目录（`rag/`）执行：

```powershell
python RAG四合一平台/run.py
```

会同时拉起四个子服务 + 门户页。浏览器打开 http://127.0.0.1:8100/ 即可点进各应用。

单独跑某个副本：

```powershell
python RAG四合一平台/apps/基础聊天机器人/main.py
python RAG四合一平台/apps/带安全校验的聊天机器人/main.py
python RAG四合一平台/apps/社交媒体文案和电商内容生成/main.py
python RAG四合一平台/apps/chroma文档管理/run.py
```

## 目录说明

```
RAG四合一平台/
  run.py                 # 一键启动
  portal/index.html      # 门户页
  frontend/dist/         # 安全聊天前端构建产物
  apps/                  # 四个项目的独立副本
```

密钥仍读取原仓库根目录的 `.env` / Windows 环境变量 `DEEPSEEK_API_KEY`。

## 注意

- 原目录 `基础聊天机器人`、`带安全校验的聊天机器人`、`社交媒体文案和电商内容生成`、`chroma文档管理` **保持原样**。
- 副本未复制 `chroma_db`（体积大）；首次启动 RAG 会按空库/示例 + `data/` 重建索引。
- 若端口被占用，先关掉对应旧进程再启动。
