这张图展示了 Corrective RAG（CRAG）的完整工作流程，比之前的图更详细，包含了知识修正（Knowledge Correction）和知识搜索（Knowledge Searching）两个核心模块
整体架构（三阶段）

代码块
Python
复制
┌─────────────────────────────────────────────────────────────┐
│  Stage 1: Retrieval（检索）                                  │
│  用户问题 x → 检索器 → 检索文档 d₁, d₂                         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────────┐
│  Stage 2: Knowledge Correction（知识修正）                          │
│  ├─ Retrieval Evaluator: 评估文档是 Correct / Ambiguous / Incorrect │
│  ├─ Knowledge Refinement: 分解→过滤→重组内部知识 k_in                │
│  └─ Knowledge Searching: 重写查询 → Web搜索 → 选择外部知识 k_ex      │
└────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Stage 3: Generation（生成）                                 │
│  根据评估结果，组合不同的知识源生成答案                         │
└─────────────────────────────────────────────────────────────┘
