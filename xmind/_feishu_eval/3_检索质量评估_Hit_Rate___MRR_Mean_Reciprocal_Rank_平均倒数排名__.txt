•
evaluate_response(query, response)：直接把查询引擎返回的 response 丢进去，评估器会自动从 response.source_nodes 里取召回上下文，无需手动拼接。
•
忠实度、相关性返回 .passing（True/False）和 .score（0/1）；正确性返回 .score（1~5 分）和 .feedback（评语）。

3、检索质量评估：Hit Rate + MRR(Mean Reciprocal Rank[平均倒数排名])
生成评估只能告诉你"答案好不好"，但定位不了"是检索的锅还是生成的锅"。检索评估专门衡量"召回的文档对不对"。LlamaIndex 用 RetrieverEvaluator，并能用 LLM 自动生成"问题→正确节点"的评测数据集，省去人工标注。

"""
RAG 检索质量评估 - LlamaIndex RetrieverEvaluator
手动构造评测集 + 用 RetrieverEvaluator 算 Hit Rate 和 MRR

本脚本演示如何手动构建评估数据集，并通过自定义逻辑计算检索系统的两个关键指标：
1. Hit Rate (命中率): 检索结果中是否包含至少一个相关文档。
2. MRR (Mean Reciprocal Rank, 平均倒数排名): 第一个相关文档在检索结果中的排名倒数的平均值。
"""

import asyncio
import os

from llama_index.core import Settings, SimpleDirectoryReader, VectorStoreIndex
from llama_index.core.node_parser import SentenceSplitter
from llama_index.embeddings.dashscope import DashScopeEmbedding
from llama_index.llms.dashscope import DashScope

# ===================== 1. 全局配置（通义千问） =====================
# 从环境变量获取 API Key，确保安全性
api_key = os.getenv("DASHSCOPE_API_KEY")

# 配置大语言模型 (LLM) 用于后续可能的生成任务或评估
Settings.llm = DashScope(model_name="qwen3.7-max", temperature=0, api_key=api_key)

# 配置嵌入模型 (Embedding Model) 用于将文本转换为向量
Settings.embed_model = DashScopeEmbedding(model_name="text-embedding-v4", api_key=api_key)

# ===================== 2. 分块建索引 =====================
# 加载本地文档数据
documents = SimpleDirectoryReader(input_files=["./data/company_info.txt"]).load_data()

# 使用句子分割器对文档进行分块，设置块大小和重叠部分以保留上下文信息
nodes = SentenceSplitter(chunk_size=120, chunk_overlap=20).get_nodes_from_documents(documents)

# 基于分块后的节点构建向量索引
index = VectorStoreIndex(nodes)

# 创建检索器，设置每次检索返回最相似的 2 个节点 (top_k=2)
retriever = index.as_retriever(similarity_top_k=2)

# ===================== 3. 手动定义评估数据集 =====================
# 为每个测试问题定义关键词，用于后续判断检索结果是否相关
# 注意：在实际生产中，通常使用人工标注的相关文档 ID 作为黄金标准 (Ground Truth)
eval_questions = [
    {
        "query": "国家天文台的主要职责是什么？",
        # 关键词列表：只要检索到的文本中包含任一关键词，即视为相关
        "keywords": ["天文台", "职责", "研究", "观测"]  # 根据实际文档内容调整
    },
    {
        "query": "天文台的地理位置在哪里？",

    },

        "query": "公司的核心业务是什么？",

    },
