二、上下文压缩（Contextual Compression）
1、核心概念
问题：召回的片段里往往只有一两句真正相关，其余是噪声。直接整段喂给 LLM 会：
•
占用大量 token（成本高、易超长）
•
噪声干扰生成，诱发幻觉
上下文压缩 = 在召回之后、生成之前，把每个片段里与问题无关的句子裁掉，只留下真正相关的内容。

一句话：重排序解决"哪些片段排前面"，上下文压缩解决"每个片段里留哪几句"。两者常配合使用：先重排，再压缩。

2、LlamaIndex 实现：SentenceEmbeddingOptimizer
LlamaIndex 内置 SentenceEmbeddingOptimizer：它把召回片段拆成句子，逐句和查询算 embedding 相似度，只保留相似度高的句子，实现"句子级"的上下文裁剪。

上下文压缩（Contextual Compression）- LlamaIndex 实现
SentenceEmbeddingOptimizer：召回后按句子相关度裁剪，只把"有用的句子"喂给 LLM

import os

api_key = os.getenv("DASHSCOPE_API_KEY")

    model_name="text-embedding-v3",
    api_key=api_key,
)

    model_name="qwen3.7-max",

    temperature=0.1,
)
